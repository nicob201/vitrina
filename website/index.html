Instalala en cuatro pasos

Primero, tres cosas que tenés que tener.

Una Mac
con Python 3.9 o más nuevo
adb
brew install android-platform-tools
Un celu Android
8 o más nuevo, con depuración USB

  1. Bajá vitrina y creá el comando

    Así podés correr vitrina desde cualquier carpeta. El último comando agrega esa carpeta a tu PATH: abrí una terminal nueva después.

    git clone https://github.com/nicob201/vitrina.git
cd vitrina
mkdir -p ~/.local/bin && ln -s "$PWD/server.py" ~/.local/bin/vitrina
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc

  2. Completá la configuración

    Corré vitrina una vez: crea config.json y avisa que falta emparejar. Poné tu usuario de GitHub, tu ciudad y la carpeta de fotos. El panel de tu Mac se activa con "mac": true.

  3. Instalá la app en el celu

    Bajá el APK del último release a tu carpeta Descargas, comprobá su huella SHA-256 con la de las notas y, con el celu enchufado por USB, instalalo.

    cd ~/Downloads
shasum -a 256 vitrina-__VERSION__.apk   # tiene que coincidir con las notas del release
adb install vitrina-__VERSION__.apk

  4. Emparejá y arrancá

    El celu confirma el emparejado y vitrina se abre sola. La primera vez te guía por los ajustes del celu que hacen falta.

    vitrina pair
vitrina start

Para frenarla: vitrina stop. Nada arranca solo, y si la Mac duerme más de una hora, vitrina se frena. El detalle completo está en el README.

Cerrada de entrada

vitrina muestra tus datos en tu escritorio, así que está hecha para que nadie más pueda verlos.

Solo el celu emparejado ve algo

Todo viaja por HTTPS con un certificado hecho en tu Mac, y cada pedido lleva una clave secreta. Sin ella, el server no responde nada útil.

Emparejar solo se puede con adb

Solo adb puede abrir la pantalla de emparejar de la app, así que ninguna otra app del celu puede apuntar vitrina a otro server.

No hay cuentas ni nube

Tus datos no pasan por ningún servidor de vitrina. Al clima se le manda solo el nombre de la ciudad, y el token de Claude solo viaja a Anthropic, nunca al celu.

No arranca sola ni toca tus archivos

Corre solo cuando vos la arrancás. No toca tus archivos ni la configuración de tu Mac: solo guarda lo suyo en su propia carpeta. El código es abierto y el APK está firmado, con su huella en cada release.
